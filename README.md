# Lutendo Damuleli – profile site

React + Vite landing page for LinkedIn.

## Run it
```bash
npm install
npm run dev        # http://localhost:5173
```

## Edit it
- Content: `src/data.js` (all text, links, skills, projects)
- Layout and components: `src/App.jsx`
- Look and feel (colours, fonts, spacing): `src/styles.css`, tokens are at the top

## Deploy (free)
**Vercel / Netlify:** push to GitHub, import the repo, accept the defaults
(build command `npm run build`, output folder `dist`).

**GitHub Pages:** `npm run build`, then publish the `dist` folder.

Put the live URL in LinkedIn under Contact info → Website, or in Featured.
